# SyncCloud v0.1.1 — 同步可靠性与实时监听修复

本版修复“立即同步”无反馈、阿里云盘同步报错，以及实时监听模式下新建或修改文件未及时上传的问题，并加强失败恢复和数据保护。

## 修复内容

- 实时监听不再被持续文件事件无限推迟：普通保存约 500 毫秒聚合，连续事件每批最多等待 2 秒；同步期间合并重复通知，保留一次后续检查。这里是触发等待，上传完成时间仍取决于扫描、在途任务和网络。
- “立即同步”返回排队、请求合并或明确失败原因；文件监控不再阻塞异步工作线程，配置更新和删除等待原任务退出。
- 阿里云盘兼容目录 `size: null`，补查未知文件大小，修复真实分片上传签名问题；覆盖上传先完成新内容，再替换旧版本。
- 修复批量上传中临时 HTTP 429 被判定为远端锁续租失败的问题：同账户控制请求共用限频与冷却，遵守服务端等待提示进行有界重试；真实失锁、过期和所有权变化仍禁止提交。
- 下载重试会重新获取签名链接，避免重复使用失效链接；返回前等待异步文件写入完成，错误保留安全的 HTTP 状态和 CDN 错误码。
- 失败、暂停、文件占用和扫描不完整时保留正确基线；上传使用稳定快照，清单、恢复日志、待替换文件与回收站恢复相互校验。
- 完善阿里、百度、S3、WebDAV 和 Git 的错误传播、变更戳、令牌刷新、流式传输及失败恢复。
- 设置保存串行处理并反馈失败；独立密码和密钥字段迁入 Windows 凭据管理器；数据目录迁移采用一致数据库备份、文件校验及写入屏障。
- 修复 GNU 构建缓存迁移和 WebView2 链接准备，统一测试与便携版构建流程。

## 验证

- Rust：98 项单元测试、12 项端到端测试通过。
- 前端：6 项回归测试通过，TypeScript 与 Vite 生产构建通过。
- 并发、持久化、凭据及实时监听改动已独立审查通过。
- 阿里云盘、百度网盘已使用专用目录验证真实上传、下载、覆盖、删除、内容哈希、清单与锁，测试目录已清理。S3/WebDAV 使用本地 HTTP 契约，Git 使用本地仓库。
- Windows 便携版内嵌核心及 WebView2Loader DLL 与 release 构建逐字节核对；资产附带 SHA-256 校验文件。

## 下载与升级

下载 Release 附件 `synccloud.exe`，适用于 Windows 10 1809 及以上 / Windows 11 x64。系统仍需 Microsoft Edge WebView2 Runtime。

升级前请从托盘退出旧版，并备份整个数据目录及旧程序，再运行新版。现有任务、同步方向和基线沿用原配置。

新版首次加载会迁移旧格式凭据。旧版不理解新的系统凭据引用，回退时需同时恢复升级前的数据备份。数据目录迁移后的原目录会保留，确认新目录正常后再清理。

## 验证边界与后续优化

本次按单电脑使用验收。多设备强原子锁协议、外部 Git 的精确限速与统一硬超时、持续事件下大目录扫描成本仍待优化；实际 GUI 长时间运行和断电场景未完成验收。系统凭据引用绑定当前 Windows 用户；URL 内嵌凭据尚待统一治理。本轮未新增存储后端或开放加密功能。
